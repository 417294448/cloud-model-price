# cloud-model-price

云模型价格对比页面：基于 LiteLLM 价格库（`source-data/model_prices_and_context_window.json`，3000+ 模型）的单文件静态页面，支持全模型浏览、多条件筛选排序与多模型并排对比。

## 使用方式

`index.html` 已内嵌全部数据（约 1.3 MB），**双击即可在浏览器中直接打开使用**，无需安装依赖、无需启动任何服务。

## 功能

- **浏览全部**：搜索模型名 / provider，按 provider、模型类型（对话/图像/嵌入等）、能力（视觉、函数调用、推理）筛选；点击列头排序；分页浏览
- **对比**：勾选最多 3 个模型，切到「对比」标签页并排查看价格（输入/输出/缓存读，美元/百万 tokens）、上下文、支持模态、能力标签，数值维度自动高亮最优值；勾选满 3 个自动跳转对比页，浏览页底部悬浮条可随时进入对比、清空选择

## 说明

- 数据价格原始单位为美元/token，页面统一换算为美元/百万 tokens 展示
- 部分模型存在阶梯定价（如 Gemini、Qwen 系列），表格中以「阶梯」标注，详细档位见源数据
- 若 `source-data/` 下的原始 JSON 更新，需要重新把最新数据内嵌进 `index.html`（把 JSON 序列化后写入文件中 `<script type="application/json" id="model-data">` 标签内），否则页面展示的仍是旧数据
